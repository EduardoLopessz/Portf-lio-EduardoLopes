# Eduardo Lopes — Portfólio

Portfólio pessoal com o visual do lobby do Valorant, mostrando quem eu sou, meus projetos, minha trajetória e minhas criações fora do código.

🔗 **Demo ao vivo:** https://eduardolopessz.github.io/Portf-lio-EduardoLopes/](https://eduardolopessz.github.io/portfolio-eduardolopes/)

## Sobre o projeto

Este site foi feito pra fugir do modelo clássico de portfólio, apresentando meu perfil como se fosse a tela de lobby de uma partida: cards de "agente", status ao vivo, barra de progresso de habilidades e navegação por abas.

## Tecnologias usadas

- HTML5 semântico
- CSS3 puro (sem framework) — variáveis CSS, Grid, Flexbox, `clip-path` para os recortes geométricos
- JavaScript puro — troca de abas, modal, animações de interface

## Seções

- **Início** — apresentação, status atual e atalhos rápidos
- **Projetos** — repositórios em destaque puxados do GitHub
- **Carreira** — nível de domínio em cada tecnologia e histórico de cursos
- **Criações** — trabalhos fora do código (música, Twitch, TikTok)
- **Sobre** — minha trajetória e contatos

## Transparência sobre uso de IA

HTML e CSS eu domino de verdade — é onde entendo o que está acontecendo em cada linha. Usei IA (Claude Code) para acelerar iteração e ajustes. O JavaScript foi construído com ajuda de IA, já que ainda estou aprendendo a linguagem.
